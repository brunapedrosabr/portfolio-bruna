# Front-end · Portfólio Bruna Pedrosa

Aplicação React + Vite + TypeScript. A documentação completa (instalação, variáveis de ambiente, deploy e estrutura de pastas) está no [README principal](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # gera a pasta dist/
npm run lint     # verifica o código com o oxlint
```
